## Mi experiencia con los comandos

Configuré mi nombre y correo en Git y cloné el repositorio hello-git. Revisé su estado con `git status` y su historial con `git log`. Agregué mi nombre a este README, lo preparé con `git add` y lo guardé con `git commit`. Después creé la rama `feature/carlomederos`, hice un cambio en ella y la fusioné en `main` con `git merge`. Por último creé este repositorio en GitHub, lo conecté con `git remote add` y subí los cambios con `git push`.
